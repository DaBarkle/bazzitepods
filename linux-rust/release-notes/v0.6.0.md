# Kase 0.6.0

**Released:** 2026-10-28 · **Type:** minor release · **Breaking changes:** new app id (migrated automatically by the installer)

BazzitePods is now **Kase**: AirPods for KDE Plasma. The new name says who the app is for without tying it to one distro. It works on any KDE Plasma desktop, Bazzite included. This release changes the name, the app id and the repository address. The features and your settings stay exactly as they were in 0.5.0.

## Highlights

- **A new name: Kase.** The app's icon is the AirPods case, and the K follows the naming tradition of KDE apps such as Konsole, Kate and Krita.
- **Updating moves you across by itself.** Your settings, saved AirPods and Flatpak overrides come with you.
- **A brand-new README** with screenshots and animations of the current app.

## Changed

- **New name and app id.** The app is now Kase, with app id `io.github.dabarkle.Kase` (was `io.github.dabarkle.BazzitePods`). The window, tray, app menu entry, app store text and installer all use the new name. ([#23])
- **Updating migrates you automatically.** When the install command finds BazzitePods, it ([#23]):
  1. copies your settings, saved AirPods (including their Bluetooth LE keys) and any Flatpak overrides to Kase,
  2. removes BazzitePods, its data and its old autostart entry,
  3. installs and starts Kase.
- **New repository address:** [github.com/DaBarkle/kase](https://github.com/DaBarkle/kase). Old `bazzitepods` links and the old install command keep working through GitHub's redirect.
- **The release bundle is now `Kase.flatpak`.** The installer picks up the bundle by itself, so nothing changes for you.
- **A rewritten README:** a tour of the island, the app window, Apple device mode and the mic switch, plus compatibility, permissions, troubleshooting and developer notes. ([#23])

## Upgrading

Run the usual install command in a terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/DaBarkle/kase/main/linux-rust/packaging/install-bazzite.sh | bash
```

You'll see a line saying your settings were moved over from `io.github.dabarkle.BazzitePods`, and then Kase appears in the tray. **Apple device mode** is a system Bluetooth setting, so it stays as it is and you don't need to turn it on again.

## Notes

- If you installed the bundle by hand with `flatpak install` instead of the install command, BazzitePods and Kase would sit side by side. Run the install command once to move your settings across and remove the old app.
- Some internal names keep the old spelling for now and are invisible in use: the `librepods` program names, the virtual mic's internal name, and the backup file Apple device mode keeps (`main.conf.bak-bazzitepods`).
