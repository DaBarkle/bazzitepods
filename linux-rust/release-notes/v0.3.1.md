# BazzitePods 0.3.1

**Released:** 2026-10-27 · **Type:** patch release, no breaking changes

This release makes battery readings more honest about where your AirPods are and adds more of the AirPods' own settings. When your AirPods are nearby but not connected to this PC, their live levels and charging state now show instead of being greyed out. When both pods are put away in a closed case, BazzitePods now says *In case* and explains how to update the case reading. The settings list gains five options that BazzitePods reads directly from your AirPods, so you only see the ones your model has.

## Added

- **More AirPods settings.** BazzitePods now offers automatic ear detection, Adaptive Audio strength (More noise, Default, Less noise), noise cancellation with one AirPod, the microphone choice (Automatic, Left or Right) and *Connect to this PC automatically*. Each setting is read from the AirPods, so only the settings your model supports appear. ([#12](https://github.com/DaBarkle/bazzitepods/pull/12))
- **"In case".** When both pods go into a closed case, the window and tray now say *In case* instead of *Not connected*. Under the case's last reading, the window also shows *open the lid to update*. ([#12](https://github.com/DaBarkle/bazzitepods/pull/12))

## Fixed

- **Charging shows while the AirPods are away from this PC.** Readings the AirPods broadcast, for example pods charging in an open case nearby, used to be greyed out with the charging bolt hidden whenever they weren't connected here. They now show live. ([#12](https://github.com/DaBarkle/bazzitepods/pull/12))
- **No stale levels that look live.** When the AirPods disconnect, their last levels change to *last seen* right away. Before, they kept looking live for up to a minute. ([#12](https://github.com/DaBarkle/bazzitepods/pull/12))
- **Personalized Volume shows its real state.** The switch used to read Off after every launch, whatever the AirPods were set to. ([#12](https://github.com/DaBarkle/bazzitepods/pull/12))

## Known issues

- **How AirPods report the case.** AirPods report the case battery only while the lid is open with at least one pod inside. iPhones work the same way. While you wear both pods, or once the lid is closed, BazzitePods shows the last reading and when it was taken.
- **Readings from nearby AirPods.** Bazzite's Bluetooth service doesn't enable the advertisement monitor, so BazzitePods only listens to the AirPods' broadcasts while they are not connected to this PC.

## Upgrading

Run the installer again. It replaces the current version and keeps your settings:

```bash
curl -fsSL https://raw.githubusercontent.com/DaBarkle/bazzitepods/main/linux-rust/packaging/install-bazzite.sh | bash
```

To install by hand instead, download `BazzitePods.flatpak` below and run:

```bash
flatpak install --user --reinstall --bundle BazzitePods.flatpak
```

## Compatibility

- **Desktops:** unchanged from 0.3.0.
- **AirPods:** all models supported by 0.3.0. New settings appear only for the models that report them.
- **Anti-cheat:** unchanged. BazzitePods doesn't inject into or hook games, and doesn't capture the screen.
