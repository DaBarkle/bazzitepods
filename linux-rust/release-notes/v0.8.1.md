# Kase 0.8.1

**Released:** 2026-10-30 · **Type:** patch release · **Breaking changes:** none

Kase now runs on 64-bit ARM. This release adds ARM64 Flatpak bundles alongside the x86_64 one, teaches the installer to pick the right bundle for your PC, and checks the installer scripts on every change. Nothing changes for x86_64 users: the app is the same as 0.8.0.

## Highlights

- **64-bit ARM support.** Raspberry Pi 5, Asahi Linux on Apple Silicon Macs, and ARM laptops get their own bundle, `Kase-aarch64.flatpak`.
- **One install command, any PC.** The installer reads your CPU type and downloads the matching bundle by itself.

## What's new

### Installing

- **ARM64 bundles.** Every release now carries `Kase-aarch64.flatpak` and `Kase-x86_64.flatpak`, built natively on GitHub's ARM and x86 runners. `Kase.flatpak` stays the x86_64 bundle, so install commands and links from before 0.8.1 keep working. ([#37])
- **The installer picks the right bundle** from `uname -m`: `x86_64` gets the x86_64 bundle, `aarch64` the ARM one. Any other CPU still gets a clear message instead of a failed install. ([#37])

### Under the hood

- **The installer is checked on every pull request.** `install.sh` and the `install-bazzite.sh` wrapper are run through shellcheck in CI, so a broken installer can't reach a release. ([#37])
- **Releases never go out empty-handed.** If the ARM build ever fails, the release still ships the x86_64 bundles, with a warning, rather than not shipping at all. ([#37])

## Compatibility

| CPU | Bundle | Notes |
| --- | --- | --- |
| x86_64 (Intel, AMD) | `Kase-x86_64.flatpak` (also `Kase.flatpak`) | unchanged from 0.8.0 |
| 64-bit ARM (aarch64) | `Kase-aarch64.flatpak` | new; see Known limitations |

Desktops, distributions and AirPods models are as in [0.8.0](https://github.com/DaBarkle/kase/releases/tag/v0.8.0).

## Upgrading

Open a terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/DaBarkle/kase/main/linux-rust/packaging/install.sh | bash
```

Kase restarts in the tray with your settings, saved AirPods and Flatpak overrides intact.

## Known limitations

- **ARM:** the ARM64 bundle is built in CI but hasn't yet been tested on real ARM hardware. If you run it on a Raspberry Pi, an Asahi Mac or an ARM laptop, please [open an issue](https://github.com/DaBarkle/kase/issues) and say how it went.
- Everything else listed for [0.8.0](https://github.com/DaBarkle/kase/releases/tag/v0.8.0) still applies, apart from its ARM note.
