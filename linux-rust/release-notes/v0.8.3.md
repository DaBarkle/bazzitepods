# Kase 0.8.3

**Released:** 2026-10-30 · **Type:** patch release · **Breaking changes:** none

Clearer wording for the battery setting added in 0.8.2. Nothing about how it works has changed; it now says what it does in plain language.

## Changed

- **The switch has a clearer name.** In **Settings → Diagnostics**, "Faster battery while away" is now **Quicker battery updates when not connected**, with an explanation you can act on: it shows your AirPods and case battery sooner when they aren't connected to this PC (for example while you're using them with your iPhone, or when you open the case nearby), it uses a newer Linux Bluetooth feature that's still labelled experimental, and Bluetooth restarts for a few seconds when you change it. ([#41])
- **The status row speaks plainly.** "Battery while away" is now **Battery when not connected**, and shows **Quick updates** or **Standard (updates less often)** instead of technical terms. The technical names stay in the log for troubleshooting. ([#41])
- The README's FAQ points to the switch when the case level is slow to update. ([#41])

## Upgrading

Open a terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/DaBarkle/kase/main/linux-rust/packaging/install.sh | bash
```

Kase restarts in the tray with your settings, saved AirPods and Flatpak overrides intact. If you already turned the switch on in 0.8.2, it stays on.
